🔷 LosaTermVoip

Terminal Manager for VoIP Engineers — SSH · SFTP · SCP · FTP · PCAP Analyzer · SIP Ladder · Syslog · H.323 · MEGACO · Skinny · SIP-I
🌐 Language / Lingua:

📋 Requisiti

LosaTermVoip è un .exe portabile (nessuna installazione). Software esterni:

SoftwareUsoNecessario
PuTTY (putty.exe, pscp.exe, psftp.exe)Terminale SSH embedded, SCP, SFTPper SSH/SCP/SFTP
Wireshark (con tshark)Analisi PCAP — Ladder SIP/H.323/MEGACO/Skinnyper PCAP
TranslatorXApertura trace SDL Cisco CUCMopzionale
.NET Framework 4.8Runtime (già presente su Win10/11)richiesto
Chrome / EdgeClaude AI in-app, apertura URLopzionale

Dati salvati in %APPDATA%\LosaTermVoip\. Le password sono cifrate con Windows DPAPI (valide solo sullo stesso PC/utente).

⚙️ Installazione

  1. Installa PuTTY e Wireshark (spunta TShark durante il setup).
  2. Copia LosaTermVoip.exe dove vuoi e avvialo: nessuna installazione.
  3. Le connessioni del vecchio NetTerm vengono importate automaticamente al primo avvio.

🔌 Connessioni

+ Nuova per crearne una. Campi: Nome, Host/IP, Porta, Protocollo (SSH·SFTP·SCP·FTP·HTTP·HTTPS), Utente, Password, Tipo VPN (nota informativa), Browser e Path (per HTTP/HTTPS).

  • Doppio-click = connetti subito (SSH embedded).
  • Tasto destro = menu (SSH finestra, SFTP, SCP, FTP, Modifica, Elimina).

🖥️ SSH

PuTTY viene incorporato nella tab. Con sessione attiva appaiono in toolbar: 📊 Analizzatore (mostra/nasconde il pannello sotto il terminale), 📄 Log, ✕ Chiudi. Ogni sessione salva un log in %APPDATA%\LosaTermVoip\logs\ analizzato in tempo reale.

📁 FTP / SFTP / SCP

FTP apre un browser file grafico (naviga, upload, download). SCP apre una finestra di trasferimento con opzione ricorsivo (-r) per le cartelle.

⚠ Su Cisco IOS l'errore unexpected end-of-file significa che il device non ha SCP/SFTP server attivo: serve ip scp server enable e un path tipo flash: (non ~/), con utente a privilegio 15.

🖧 Server (FTP / SFTP)

Il pulsante 🖧 Server trasforma il PC in server FTP (TcpListener puro, modalità PASV) o configura il server SFTP via OpenSSH di Windows. Utile per ricevere file da gateway/SBC.

🔍 Analizzatore & 📦 PCAP / Ladder

L'analizzatore esamina i log SSH e i PCAP, evidenziando eventi con severità colorata (Critical/Error/Warning/Info). Regole per CUBE (IOS Voice Gateway) e CUCM.

Ladder Diagram

  • Apri un PCAP col pulsante 📦 PCAP oppure trascinandolo nella finestra.
  • Diagramma a scala con endpoint (IP:porta) e frecce dei messaggi col timestamp.
  • Filtra per chiamata: il menu a tendina mostra ogni call come chiamante → chiamato [ora] N msg; selezionala per isolare solo quei messaggi.
  • Doppio-click o 🔍 Segui call per evidenziare l'intera conversazione.
  • SIP, H.323, MEGACO e Skinny sono unificati e ordinati per timestamp.

📖 Doc.

Raccolta di link alla documentazione, modificabile a mano: Aggiungi / Modifica / Rimuovi / Apri, con filtro per categoria. Preset inclusi (CUCM SRND, CUBE, AudioCodes). Doppio-click apre nel browser. Salvato in doclinks.json.

📡 Syslog Server

Il pulsante 📡 Syslog apre un server syslog UDP in stile AudioCodes/Cisco.

  • Scegli la porta (default 514) e premi Avvia. Configura il device per inviare i syslog all'IP del PC.
  • Severità colorate, evidenziazione dei messaggi SIP, filtro testo, "Solo SIP/Call", scrittura su file ed export.
  • Ferma rilascia la porta. Se 514 risulta occupata da una sessione chiusa male, usa 1514 o riavvia il PC.

🖱️ Drag & Drop

Trascina un file nella finestra e scegli l'azione:

  • .pcap / .cap → Analizza qui (Ladder) oppure viewer Syslog.
  • log / trace → Apri in TranslatorX (trace SDL Cisco CUCM) oppure viewer Syslog (AudioCodes).

🔧 Troubleshooting

SSH non parte

Metti putty.exe accanto all'exe o in C:\Program Files\PuTTY\.

PCAP non funziona

Installa Wireshark con TShark; riavvia l'app.

Ladder "Nessun messaggio SIP"

SIP su porta non standard: in Wireshark usa Decode As per assegnare la porta a SIP.

Syslog: porta 514 occupata

Una sessione chiusa male lascia un socket orfano: chiudi con Ferma, usa la 1514 o riavvia il PC.

TranslatorX "No known messages"

TranslatorX apre solo trace SDL Cisco, non pcap né syslog AudioCodes.

Connessioni/password

Salvate in %APPDATA%\LosaTermVoip\connections.json, cifrate con DPAPI: valgono solo sullo stesso PC/utente.

Diagrama Ladder

  • Abre un PCAP con el botón 📦 PCAP o arrastrándolo a la ventana.
  • Diagrama con extremos (IP:puerto) y flechas de mensajes con marca de tiempo.
  • Filtrar por llamada: el desplegable muestra cada llamada como llamante → llamado [hora] N msg; elígela para aislar solo esos mensajes.
  • Doble clic o 🔍 Seguir llamada para resaltar toda la conversación.
  • SIP, H.323, MEGACO y Skinny se unifican y ordenan por marca de tiempo.

📡 Protocolos

📞

SIP / SIP-I

INVITE, BYE, REGISTER, OPTIONS, respuestas 1xx-6xx, SDP/códecs, ISUP encapsulado.

🔷

H.323

H.225 (Setup, Connect, ReleaseComplete), H.245, RAS.

🎛️

MEGACO / H.248

ServiceChange, Add/Subtract/Modify, Notify.

☎️

Skinny / SCCP

Register, CallState, OpenReceiveChannel, StartMediaTransmission.

📖 Doc.

Una colección de enlaces a documentación, editable a mano: Añadir / Editar / Quitar / Abrir, con filtro por categoría. Preajustes incluidos (CUCM SRND, CUBE, AudioCodes). Doble clic abre en el navegador. Guardado en doclinks.json.

📡 Servidor Syslog

El botón 📡 Syslog abre un servidor syslog UDP al estilo AudioCodes/Cisco.

  • Elige el puerto (por defecto 514) y pulsa Iniciar. Configura el dispositivo para enviar syslog a la IP del PC.
  • Gravedades en color, resaltado de mensajes SIP, filtro de texto, «Solo SIP/Call», escritura a archivo y exportación.
  • Detener libera el puerto. Si el 514 está ocupado por una sesión mal cerrada, usa 1514 o reinicia el PC.

🖱️ Arrastrar y soltar

Arrastra un archivo a la ventana y elige la acción:

  • .pcap / .cap → Analizar aquí (Ladder) o visor Syslog.
  • log / traza → Abrir en TranslatorX (traza SDL de Cisco CUCM) o visor Syslog (AudioCodes).

🔧 Solución de problemas

SSH no arranca

Pon putty.exe junto al exe o en C:\Program Files\PuTTY\.

PCAP no funciona

Instala Wireshark con TShark; reinicia la app.

Ladder muestra «Sin mensajes SIP»

SIP en puerto no estándar: en Wireshark usa Decode As para mapear el puerto a SIP.

Syslog: puerto 514 ocupado

Una sesión mal cerrada deja un socket huérfano: cierra con Detener, usa 1514 o reinicia el PC.

TranslatorX «No known messages»

TranslatorX solo abre trazas SDL de Cisco, no pcaps ni syslog AudioCodes.

Conexiones/contraseñas

En %APPDATA%\LosaTermVoip\connections.json, cifradas con DPAPI: válidas solo en el mismo PC/usuario.
