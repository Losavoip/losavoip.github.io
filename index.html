The toolkit

Everything in one window. More tools land as the project grows — tell me what you need.

New
🩺

1-click SIP Health Check

Enter a domain and get a full DNS → TLS/cert → SIP OPTIONS check with a 0-100 score and the exact issues. The fastest way to find why a trunk is down.

New
🧪

Environment Check (per vendor)

Pick your vendor — Teams Direct Routing, AudioCodes, Ribbon, Cisco CUBE/CUCM, Asterisk, FreeSWITCH, Alcatel, Yeastar, 3CX — and get automated DNS/TLS/OPTIONS checks plus a vendor-specific readiness checklist and debug-command cheat-sheet.

New
🩺

SBC Health

Vendor-neutral trunk diagnostics: SIP OPTIONS test, TLS certificate & expiry check, DNS SRV/A lookup. Works on Teams Direct Routing, AudioCodes, Ribbon, Cisco CUBE, Asterisk.

🪜

SIP Ladder (PCAP & SDL)

Turn PCAPs and Cisco SDL/SDI traces into clean SIP ladder diagrams — grouped per Call-ID like Wireshark, with auto-diagnosis, RTP/MOS voice quality and per-message RFC 3261 conformance checks.

New
📊

Call Quality Scorecard

Every captured call gets a 0-100 voice-quality score (MOS, packet loss, jitter) and a one-line root cause — one-way audio, degraded audio, codec mismatch — right in the call diagnosis. The "wow" that goes straight into a ticket.

📟

Syslog Server

Built-in UDP syslog collector with a live viewer and SIP-only filter — no extra software.

🔀

SIP Simulator & Cause Codes

Craft and send SIP messages, translate Q.850 ⇄ SIP cause codes, and analyze SDP/codecs.

🖥️

SSH / Telnet

Tabbed PuTTY-based terminal with quick-connect profiles and a live log analyzer.

New
🔌

Serial Console

Console gateways, SBCs and routers over COM — embedded in a tab, with the same live analyzer as SSH.

📁

File & Boot Servers

Spin up FTP / SFTP / TFTP / DHCP servers for config & firmware transfers and lab provisioning.

🧰

Net Tools

Ping, traceroute, TCP port check, MTU discovery and NTP check — all in one panel.

📖

Debug Commands

A per-vendor cheat-sheet of the right debug/capture commands: Cisco CUBE/CUCM, AudioCodes, Ribbon, Teams, Asterisk and more.

New
🗺️

Network Path (LLDP/CDP)

Which switch and port are you on? LLDP/CDP discovery (switch, port, VLAN, model) plus an L3 traceroute: PC → switch → gateway → core → firewall → internet.

🧰

Full VoIP diagnostic suite

RTP player & DTMF, OPTIONS monitor, DNS NAPTR/SRV, STUN & NAT type, firewall check, SRTP/DTLS analyzer, SIP builder with Digest auth, provisioning viewer, SIP-over-WebSocket, traffic generator, codec/MOS calculators, Teams Direct Routing readiness, per-tool & combined HTML reports, RFC 3261 conformance…

✨
