LosaTermVoip
For VoIP & Network Engineers v1.1 · Beta

A terminal built for VoIP troubleshooting

A free, no-nonsense terminal with built-in tools for analyzing Cisco SDL traces, syslog and SIP signaling. Made by an engineer, for engineers.

The toolkit

Everything in one window. More tools land as the project grows — tell me what you need.

New
🩺

SBC Health

Vendor-neutral trunk diagnostics: SIP OPTIONS test, TLS certificate & expiry check, DNS SRV/A lookup. Works on Teams Direct Routing, AudioCodes, Ribbon, Cisco CUBE, Asterisk.

🪜

SDL Ladder Viewer

Turn Cisco CallManager SDL/SDI traces into clean SIP ladder diagrams.

📟

Syslog Server

Built-in UDP syslog collector with live viewer — no extra software.

🔀

TranslatorX Launch

One-click hand-off of traces and pcaps to TranslatorX.

🖥️

SSH / Telnet

Tabbed terminal with saved layouts and quick-connect profiles.

📁

FTP / SFTP Server

Spin up a temporary file server for config and firmware transfers.
